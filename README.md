# Himeshi & Madhawa — Wedding Invitation

Run locally:

```sh
npm ci
npm run dev
```

The invitation opens with a layered beach scene and leads to a responsive wedding home. Guest links, RSVP responses, and the admin dashboard use Supabase.

For the current Supabase RSVP setup, admin workflow, Cloudflare Pages deployment details, live URLs, dependencies, and troubleshooting, see [PROJECT_DOCUMENTATION.md](./PROJECT_DOCUMENTATION.md).
